ARCHITECTURE names `index.ts` as the listener; here `main.ts` listens and `index.ts` exports the default-configured `app` with no side effects, so `tests/smoke/server.test.ts` (not editable here) still passes. `pnpm start` and `pnpm dev` run `main.ts`. A request with no `Host` header (only an in-process call) passes the Host guard; every real HTTP request carries one. `KENSAKU_PORT` exists for tests and defaults to 8787; the address stays fixed at 127.0.0.1.
